# Rubik Cube Interactive Project

## Files:

- **index.html** : main page + script logic (cube model, rendering, moves, shuffle, solver)

## Usage:

Open index.html in a browser. Use move buttons to perform moves; click Shuffle to run the top-layer algorithm F R U R' U' F'; click Solve to repeatedly run algorithm R U R' U R U2 R' until solved or max iterations reached. Steps and logs are shown.
